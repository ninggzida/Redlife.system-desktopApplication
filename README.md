# RedLife

## Sobre o Projeto

O **RedLife** é um projeto acadêmico inspirado em um Trabalho Integrador desenvolvido durante minha graduação em Análise e Desenvolvimento de Sistemas. O objetivo principal deste projeto foi colocar em prática conceitos de programação, banco de dados e desenvolvimento de aplicações desktop utilizando **C#** e **SQLite**.

Este projeto foi desenvolvido com foco no aprendizado e na evolução das minhas habilidades como desenvolvedor. Durante sua construção, utilizei não apenas os conhecimentos adquiridos em sala de aula, mas também pesquisas em documentações oficiais, fóruns, vídeos, tutoriais e conteúdos disponibilizados pela comunidade de desenvolvimento.

## Objetivos

* Aprender e praticar programação em C#;
* Desenvolver habilidades com banco de dados SQLite;
* Compreender conceitos de CRUD (Create, Read, Update e Delete);
* Aplicar lógica de programação em um projeto real;
* Ganhar experiência com desenvolvimento de sistemas desktop.

## Aviso

Este projeto não foi desenvolvido exclusivamente com meus conhecimentos prévios. Assim como ocorre no dia a dia da área de tecnologia, grande parte do aprendizado envolveu pesquisa, consulta a documentações, fóruns e materiais educacionais.

O objetivo não foi demonstrar domínio completo da tecnologia, mas sim aprender, experimentar e evoluir como desenvolvedor através da prática.

## Tecnologias Utilizadas

* C#
* .NET / Windows Forms
* SQLite
* SQL

## Aprendizados

Durante o desenvolvimento deste projeto, pude aprimorar conhecimentos relacionados a:

* Programação orientada a objetos;
* Manipulação de banco de dados;
* Estruturação de projetos;
* Resolução de problemas;
* Pesquisa e aprendizado contínuo.

## Considerações Finais

O RedLife representa uma etapa importante da minha jornada de aprendizado em desenvolvimento de software. Embora eu ainda esteja em constante evolução profissional, este projeto demonstra meu interesse em aprender novas tecnologias, enfrentar desafios e construir soluções práticas.

Meu objetivo é continuar estudando, desenvolvendo novos projetos e adquirindo experiência para me tornar um profissional cada vez mais qualificado na área de tecnologia.
